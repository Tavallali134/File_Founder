# File_Founder

Created by Amir Mohammad Tavallali Nia!

A simple Python tool for finding multiple files and folders by name and quickly copying, moving, or removing them in bulk.

## What is it useful for?

This tool is useful for performing the same operation on multiple files or folders based on their names. It searches the selected folder and its subfolders for matching files and directories.

It is useful for organizing files, collecting specific files from large folders, moving multiple items, or removing unwanted files in bulk.

## Commands

`copy`: Copies matching files and folders to the destination folder.

`move`: Moves matching files and folders to the destination folder.

`remove`: Removes matching files and folders.

## Names

The names to search for should be placed in a `names.txt` file next to the Python script.
